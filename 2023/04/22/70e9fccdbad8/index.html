(1)net use命令

  • 简介

    利用该命令可以与目标机器建立连接，包括空连接或用户登录连接。空连接没有任何操作权限，如果使用用户账户登录建立连接则具有该账户的权限。可以使用该命令进行明文传递进行移动。

  • 明文传递连接域控

    格式：net use \\目标IP\ipc$ "用户密码" /user:域用户名

    或：net use \\目标IP\ipc$ "用户密码" /user:完整域名\域用户名

    以域管理员的权限查看域控的C盘内容

    如果没有建立连接，查看是访问受限的

(2)psexec

  • 简介

    ProcDump 是一个命令行实用工具，其主要用途是监视应用程序的 CPU 峰值，并在出现峰值期间生成故障转储，管理员或开发人员可以使用这些转储来确定峰值的原因。 ProcDump 还包括挂起窗口监视 (使用 Windows 和任务管理器使用) 、未经处理的异常监视的窗口挂起定义，并且可以基于系统性能计数器的值生成转储。 它还可用作可嵌入到其他脚本中的常规进程转储实用工具。
