2.Hydra

Hydra是一款非常强大的暴力破解工具，它是由著名的黑客组织THC开发的一款开源暴力破解工具。Hydra是一个验证性质的工具，主要目的是：展示安全研究人员从远程获取一个系统认证权限。

Syntax: hydra [[[-l LOGIN|-L FILE] [-p PASS|-P FILE]] | [-C FILE]] [-e nsr] [-o FILE] [-t TASKS] [-M FILE [-T TASKS]] [-w TIME] [-W TIME] [-f] [-s PORT] [-x MIN:MAX:CHARSET] [-c TIME] [-ISOuvVd46] [-m MODULE_OPT] [service://server[:PORT][/OPT]]

  • --level=5 --risk=3 设置扫描等级

    一共有5个探测等级，默认是1。等级越高，说明探测时使用的payload也越多。其中5级的payload最多，会自动破解出cookie、XFF等头部注入。当然，等级越高，探测的时间也越慢。这个参数会影响测试的注入点，GET和POST的数据都会进行测试，HTTP cookie在level为2时就会测试，HTTP User-Agent/Referer头在level为3时就会测试。在不确定哪个参数为注入点时，为了保证准确性，建议设置level为5

    一共有3个危险等级，也就是说你认为这个网站存在几级的危险等级。和探测等级一个意思，在不确定的情况下，建议设置为3级，--risk=3

Direction(方向)

指定来源或目的地。基于传输方向过滤默认使用src or dst。

###### 1、源src

src表示只捕获源地址为指定主机或端口的数据包。

###### 2、目标dst

dst表示只捕获目标地址为指定主机或端口的数据包。

###### 3、源或目标src or dst

src or dst表示只捕获源或目标地址为指定主机或端口的数据包。

###### 4、源和目标src and dst

src or dst表示只捕获源和目标地址为指定主机或端口的数据包。

###### 5、特殊方向

wireshark另外提供两种特殊方向捕获过滤器(广播brocadcast和多播multicast)

Host(s)

指定主机地址。基于类型捕获过滤，可使用类型有host(主机)、net(网段)、port(端口)、portrange(端口范围)。默认使用host。

###### 1、主机host

host用来指定捕获某主机发送和接收的数据包。语法：host [host ip]

###### 2、网段net

net指定捕获哪个网段主机的数据包，有三种形式。

（1）net net形式。第一个net为关键字，第二个net为指定的网段。

（2）net mask形式。单独指定IP地址和掩码。

（3）net CIDR形式

###### 3、端口port

port用来指定捕获某端口发送和接收的数据包。语法：posr [port]

###### 4、端口范围portrange

portrange用来指定某个端口范围发送和接收的数据包。语法：portrange [port1-port2]

###### 5、特殊类型

特殊类型gateway表示捕获源或目标为指定以太网地址的包。

Other expression(其他表达式)

使用其他表达式捕获过滤器。

可通过结合逻辑运算符同时使用多个捕获过滤器。not(!)、and(&&)、or(||)

(2)显示过滤器

Expression可以为任意原语形式的过滤表达式，由字段名称、关系(条件)和值组成。各条件操作符如下：

< lt 小于 frame.len < 64
>= ge 大于等于 frame.len >= 64
<= le 小于等于 frame.len <= 64
contains 包含某个字符串 http.host contains cisco
match 某串字符匹配某个条件 http.host match www.cisco.com
&& and 逻辑与 ip.src == 192.168.1.100 and ip.dst == 192.168.1.101
|| or 逻辑或 ip.src == 192.168.1.100 or ip.src == 192.168.1.101
! not 逻辑非 not arp and not icmp

7、Nmap扫描

参数 说明
-sT TCP connect()扫描，会在目标主机的日志记录中记录大批连接请求和错误信息
-sS 半开扫描，很少有系统能够把它记录到系统日志。需要root权限
-sF -sN 秘密FIN扫描、Xmas Tree、NULL扫描模式
-sP ping扫描，扫描端口时默认使用ping扫描，只有主机存活时才继续扫描
-sU UDP扫描，但此方式不可靠
-sA 此扫描方法通常用来穿过防火墙的规则集
-sV 探测端口服务版本
-P0 扫描之前不需要用ping命令，有些防火墙禁止用ping命令。可以使用此选项进行扫描
-v 显示扫描过程，推荐使用
-h 帮助选项，帮助文档
-p 指定端口，格式如：1~65535、1433、135、80等
-O 启动远程操作系统检测，存在误报
-A 全面系统检测、启动脚本检测、扫描等
-oN/-oX/-oG 检报告写入文件，分别是正常、XML、grepable三种格式
-T4 针对TCP端口禁止动态扫描延迟超过10ms
-iL 读取主机列表，例如: -iL C:.txt
