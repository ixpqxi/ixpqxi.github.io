2 撤销操作

  • 撤销错误的提交

    本次提交：少添加了文件、commit 信息有误、忘记 ignore 导致多添加了文件，或者没有添加某些修改

    1. 忘记 ignore 的先使用 git rm <filename> 将文件从暂存区中清除，随后在 .gitignore 中添加规则，最后 git add

    2. 少添加了文件和少添加修改情况则可以 git add 想要在本次提交追加的文件

    上面两种情况修正后，使用如下命令将提交一次新 commit 以覆盖错误的提交，日志中只会保存新的一次 commit

  • 撤销暂存

    粗心地使用 git add . 把所有文件添加到了暂存区，包括了不想在本次提交的文件，使用如下命令撤销多添加到暂存区的文件

    在 git2.23.0 版本后可以使用 git restore 替代

  • 撤销修改

    对已存在暂存区中的文件进行修改，使用如下命令可以撤销修改，将文件恢复到上一次提交的状态

    在 git2.23.0 版本后可以使用 git restore 替代

  • reset 回滚

    --soft 软回滚，保留文件修改，保留添加的暂存，仅移动 HEAD 到指定位置

    --mixed 混合回滚，默认模式，保留文件修改，取消暂存，并移动 HEAD 到指定位置

    --hard 硬回滚，清除文件修改，取消暂存，将暂存状态和文件内容完全恢复到指定位置

    --hard 回滚会强制删除文件修改，建议思考清除再使用，若硬回滚失误并且回滚前有 commit 则可以使用 git reflog 查看全部日志以找回误删的 commit
