2.2 漏洞利用

因为一个 book 结构内有一个用于输出 context 的回调函数指针，所以攻击思路为：将该函数指针覆盖为shellcode的目标目标地址

2.2.1 如何覆盖回调函数指针

因为程序存在一个 UAF 漏洞，考虑每一个 book 结构大小为 0x110, 根据堆分配器的管理机制可知其被 free 后会放入 unsorted bin 中，这是一个 FIFO 的双向链表结构

因此我们可以利用 book4 覆盖 book3 的回调函数指针

2.2.2 跳转到哪里

我们可以使用 pwndbg 的 vmmap 命令可以看到程序的堆内存是可执行的

那么可以选择一个堆地址作为 shellcode 的目标地址。需要先泄露和堆有关的地址信息，观察程序发现存在一个全局变量存储 book 指针列表

新分配的 book4 的 context 可以覆盖 book3 的回调函数指针，同样可以覆盖 book3 的 context 指针，我们可以将 book3 的 context 指针覆盖为存储 book 指针列表的全局变量地址 0x080ECA00 随后打印 book3 的 context，那么打印出的最开始的4个字节应该是 book1 的起始地址，攻击脚本实现如下
